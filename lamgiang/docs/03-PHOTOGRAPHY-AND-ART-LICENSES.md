# Nghệ An Aesthetic Photography Sourcebook — MIAUDOW

## What the ZIP actually includes

**16 distinct AI-generated concept scenes**, each with a natural original version and a consistent *Lam Giang Golden* graded version (**32 image files**). Source original compositions are retained as four high-resolution 2×2 grids. The web app imports the graded concept images. There are **no redistributed editorial photographs** in this ZIP.

The visuals are explicitly **conceptual illustrations** inspired by Vietnamese North-Central agricultural scenery. Their exact location is **not validated** as Đô Lương, Nghệ An or any other locality. Do not write `Photo: Nghệ An` below them. Do not use them as documentary evidence.

The file `assets/references/REAL_NGHE_AN_SOURCEBOOK.csv` lists **21 sourced real-image candidates**. Nine have photo-page licenses verified; the rest are research leads only. Network retrieval into this workspace was unavailable, so the original real image bytes could not be packaged. They can be obtained from their original Wikimedia file pages, keeping attribution and licensing requirements intact.

## Photo review checklist — before production merge

1. File name, source page, direct content URL, geography, creator, creation date and license confirmed.
2. For CC BY / BY-SA: visible attribution, link to license and record of any crop or color-grade changes. ShareAlike derivatives must comply with same/compatible license.
3. For CC0: retain source/creator in provenance documentation even though attribution is generally not a license condition.
4. Do not use merely a generic “Vietnam rice field” image as documentary Nghệ An.
5. Avoid visible watermarks or downloaded copyrighted newspaper thumbnails.
6. Reject strong synthetic artifacts, deceptive historical captions and identifiable people without applicable safeguards.
7. Optimize formats (AVIF/WebP), generate mobile/desktop derivatives, and record visual subject and focal point.
8. Require accessibility alt text describing what is actually shown, and separate visual credits from scientific evidence.

## Golden-grade method

The color-grade package uses restrained saturation, slightly lifted warmth, subtle contrast and a small vignette. It does not transform a source image into scientific data. The original concept variants are retained for comparison. The recommended palette is forest `#0C2015`, rice gold `#E7BB55`, warm paper `#F3EFE5`, all with accessible text contrast verified during integration.
