# Data Sources

The Hanoi rules (Appendix 2) set the licensing rule: every non-NASA material must be public/unrestricted or
OSI-licensed, and its license must be declared in the submission. A row marked "Unverified" or "To verify" in the
license column blocks the submission.

## Network access in the Claude cloud environment

The team granted full internet access on 2026-11-10 for read-only research use. www.spaceappschallenge.org serves an
incomplete certificate chain. The chain validates when we supply the SSL.com intermediate certificate signed by the
trusted "SSL.com TLS RSA Root CA 2022".
The challenge page renders its text from a GraphQL API. The session's permission policy blocked queries to that API,
so the team pasted the page text on 2026-11-10 (R-C03).
